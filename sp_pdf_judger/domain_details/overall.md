# 목적

모든 회사와 모든 제품에 공통으로 적용하는 검수 Rule 목록이다. 회사 및 제품 디테일은 이 문서에 추가로 적용한다.

이 문서는 최신 Spreadsheet의 A/B/C 번호 체계를 기준으로 검수 요구사항을 식별 가능한 Rule ID로 정리한다. Markdown에 Rule이 적혀 있다는 사실과 Python 코드에서 해당 Rule을 결정적으로 검증한다는 사실은 구분한다.

# 근거 우선순위

1. 현재 제출된 SP 문서의 명시적 시험기준과 시험결과
2. 현재 문서와 연결된 허가서 및 공인 기준 문서
3. 코드에 구현된 결정적 비교 규칙
4. RAG 검색 근거
5. 전체·회사·제품 디테일

하위 근거로 상위 근거의 명시적 값이나 결과를 덮어쓰지 않는다. 문서에 없는 수치, 날짜, 제조번호, 판정을 추정해 만들지 않는다.

# A. 구조적 정합성

## A.1 문서 버전 불일치

SP 문서의 각 페이지 또는 문서 내 여러 위치에 기재된 버전 정보를 확인하고, 동일 문서 내에서 반복 기재된 버전 값을 서로 비교한다.

서로 다른 버전 값이 확인되는 경우 '문서 버전 불일치'로 판정한다.

## A.2 페이지 누락

SP 문서 각 페이지에 기재된 현재 페이지 번호와 전체 페이지 수를 확인한다.

페이지 번호가 1페이지부터 마지막 페이지까지 연속적으로 존재하는지, 또는 전체 페이지 수와 실제 확인된 페이지 수가 일치하는지 확인한다.

둘 중 하나라도 어긋나는 경우 '페이지 누락'으로 판정한다.

## A.3 공정 항목 누락

제조요약도에 기재된 각 제조단계 및 공정 항목을 확인한 후, 해당 항목이 상세제조기록에 모두 기재되어 있는지 비교한다.

제조요약도에 존재하는 제조단계 또는 공정 항목이 상세제조기록에서 확인되지 않는 경우 '공정 항목 누락'으로 판정한다.

## A.6 시험 단위 연결

각 시험항목의 시험기준과 시험결과에 기재된 단위를 확인하고, 해당 시험에 적용되는 허가사항 또는 시험기준과 연결한다.

허가사항에 단위가 명시된 경우 해당 단위를 참조한다.

별도의 허가 기준이 없는 자사시험의 경우 해당 시험기준에 기재된 단위를 참조하여 시험결과 단위와 비교할 수 있도록 한다.

## A.7 대한민국약전·생기법 일반시험법 연결

시험방법에 대한민국약전 또는 「생물학적제제 기준 및 시험방법」의 일반시험법이 기재되어 있는 경우, 시험명과 시험방법을 해당 공정서의 시험법과 연결한다.

연결된 시험법에서 시험기준과 단위 정보를 확인하여 SP에 기재된 시험기준 및 단위와 비교할 수 있도록 한다.

## A.8 유럽약전 시험법 연결

시험방법에 유럽약전(Ph. Eur.)이 기재되어 있는 시험항목을 식별하고, 해당 시험명과 시험방법을 유럽약전의 해당 시험법과 연결한다.

## A.10 최신 허가사항 반영 SP 버전 비교

최신 허가사항이 반영된 SP 문서 버전과 회사가 제출한 SP 문서 버전을 비교하여 서로 일치하는지 확인한다.

## A.11 SP 포맷 일치도

SP 문서의 포맷을 학습해서 제출한 SP 문서를 검토할 때 전체적인 포맷 일치도를 검토할 수 있는지 확인한다.

문서 버전 일치 고도화를 위한 확인 항목이다.

## A.12 문서 버전 하단 날짜 일치

문서 버전 밑에 있는 날짜를 인식하여 일치하는지 확인한다.

## A.13 페이지·목차·시험표 연결

페이지 번호가 순서대로 되는지, 목차 번호가 순서대로인지, 각 시험에 맞는 표가 연결되고 있는지 확인한다.

## A.14 중간 페이지 누락

SP 문서 중간에 한 장이 누락되는 경우를 페이지 번호를 기준으로 보고 판별할 수 있는지 확인한다.

## A.15 제조공정 및 시험 항목 누락

제조공정 중 누락된 항목을 확인한다.

공정 중 최종원액에 대한 공정이 누락되거나, 혹은 최종원액의 무균시험에 대한 항목 1개가 누락되는 경우가 있는지 확인한다.

## A.16 약어·단위·생기 용어 인식

IU/mL 단위, PCR 시험의 바이러스 항목(CoV, RBD PAb 등), 생기일반, 생기각조 용어를 약어 또는 단위로 인식하는지 확인한다.

## A.17 제조요약도 정보 비교

제조 요약도의 정보들을 추출하여 해당 항목들과 비교하여 서로 일치하는지 확인한다.

## A.18 완제의약품 제조년월일 추출 기준

완제의약품의 제조년월일을 판단해야 하는데 다른 항목으로 추출하여 비교하진 않는지 확인한다.

## A.19 시험 방법·시험 결과 추출 구분

시험 방법이면 시험법에 대한 내용, 시험 결과면 수치에 대한 내용처럼 올바르게 추출되는지 확인한다.

## A.20 표 추출 정합성

표를 추출했을 때 각 시험 기준과 결과값이 정상적으로 추출되고 있는지 확인한다.

## A.21 시험 중복 인식 방지

한 개의 시험이 두 번 인식되고 있지 않는지 확인한다.

## A.22 판정 근거 추적성

어떤 판정에 충족, 불충족, 보류로 판정했을 때 그 기준과 결과를 클릭 가능하게 만들고, 이동했을 때 어떤 사유로 판정했는지 명시한다.

# B. 계산 및 수치 정합성

## B.1 기준 우선순위

허가사항에 해당 시험항목의 시험기준이 명시되어 있는 경우, 이를 비교·판정에 사용할 우선 기준으로 판별한다.

허가사항에 기준이 없는 경우 자사 시험기준, 즉 시험성적서에 기재된 기준으로 판별한다.

본 항목은 개별 판정을 산출하지 않으며, 이후 항목들이 기준값을 정할 때 적용하는 원칙이다.

## B.2 특정 기준값 판정

시험기준에서 특정 기준값이 명시되어 있는 경우 시험결과값이 해당 기준값을 만족하는지 확인한다.

일치하는 경우 충족, 일치하지 않는 경우 불충족으로 판정한다.

## B.3 단위 정합성

허가사항 또는 시험기준에 단위가 명시되어 있는 경우, 시험결과에 기재된 단위가 해당 기준 단위와 동일하게 기재되어 있는지 확인한다.

시험결과에 기재된 단위가 기준 단위와 같으면 충족, 다른 경우에는 환산 가능 여부와 무관하게 불충족으로 판정한다.

## B.4 소수점 이하 자릿수 일치

허가사항 또는 시험기준의 수치가 소수점 이하 자릿수를 포함하여 명시된 경우, 시험결과값도 동일한 소수점 이하 자릿수로 기재되어 있는지 확인한다.

자릿수가 일치하면 충족, 일치하지 않는 경우 불충족으로 판정한다.

## B.5 비교조건 판정

시험기준에 이상(≥), 초과(>), 이하(≤), 미만(<) 등의 비교조건이 명시되어 있는 경우, 해당 비교조건을 시험결과에 적용하여 기준 충족 여부를 확인한다.

조건을 만족하면 충족, 만족하지 않으면 불충족으로 판정한다.

## B.6 최소값·최대값 범위 판정

시험기준에 최소값과 최대값이 함께 설정되어 있는 경우, 시험결과가 하한과 상한으로 구성된 허용범위 내에 포함되는지 확인한다.

포함되는 경우 충족, 포함되지 않는 경우 불충족으로 판정한다.

## B.7 총합 재계산

복수의 개별 측정값을 합산하여 최종 결과를 산출하는 시험의 경우, 개별값의 합계를 재계산하여 문서에 기재된 총합값과 일치하는지 확인한다.

일치하는 경우 충족, 일치하지 않는 경우 불충족으로 판정한다.

## B.8 복수 조건 모두 충족

하나의 시험기준에서 둘 이상의 서로 다른 조건을 모두 충족하도록 요구하는 시험의 경우, 각 조건을 개별적으로 확인하고 모든 조건이 충족되는지 확인한다.

조건을 만족하면 충족, 만족하지 않으면 불충족으로 판정한다.

## B.9 복수 조건 중 최소 요구 개수 충족

하나의 시험기준에서 복수 조건 중 하나 이상을 충족하도록 요구하는 경우, 각 조건을 확인하여 최소 요구 개수 이상의 조건이 충족되는지 확인한다.

조건을 만족하면 충족, 만족하지 않으면 불충족으로 판정한다.

## B.10 복수 대상 또는 목표값 누락 확인

시험기준에서 복수의 특정 대상 또는 목표값을 모두 확인하도록 요구하는 경우, 시험결과에 해당 대상이 누락이 없는지 확인한다.

조건을 만족하면 충족, 만족하지 않으면 불충족으로 판정한다.

## B.11 시험 횟수·시험단계별 기준 선택

시험 횟수 또는 시험단계에 따라 서로 다른 기준이 적용되는 경우, 현재 적용되는 시험단계를 확인한 후 해당 단계에 설정된 기준으로 시험결과를 확인한다.

일치하지 않는 경우 불충족으로 판정한다.

## B.12 대상별 표 형식 판정

시험기준에 복수의 판정조건이 설정되어 있고 시험결과가 대상별 표 형식으로 기재된 경우, 각 대상의 시험결과를 해당 판정조건과 각각 대응하여 모든 조건이 충족되는지 확인한다.

충족하지 않는 경우 불충족으로 판정한다.

## B.13 단위와 연산자 동시 비교

1.3 IU/mL일 경우 단위와 연산자를 함께 비교하여 시험 결과값을 판정한다.

## B.14 범위 기준 확인

7.0~8.0 같은 범위 기준을 확인한다.

## B.15 정성 표현 인식

'검출되지 않아야 함'이라는 기준에 대한 결과값이 '검출되지 않음', '불검출', 'X' 등 여러 가지 표현으로 기재된 경우 이를 인식하고 판단하는지 확인한다.

## B.16 복합 조건 분해 판정

'~않아야 하며, ~는 ~% 이하'라는 시험 기준을 조건별로 나누어 각각 만족하는지 확인한다.

박테리오파지부정시험도 합격으로 잘 되고 있는지 확인한다.

## B.17 유효자릿수 정합성

8.0 미만이라고 적혀있으면 7.66은 수치상으로는 통과이나, 유효자릿수가 일치하는지 확인해야 한다.

유효자릿수에 대한 내용은 허가사항이나 약전 등에 기입되어 있지 않으므로 시험 기준에 나와있는 유효 자릿수로 판단해야 한다.

## B.18 신청제품정보와 본문 정보 일치

신청제품에 대한 정보와 본문의 내용을 서로 비교하여 서로 일치하는지 확인한다.

## B.19 신청제품정보 최종 유효년월일 계산

신청제품정보에 기재된 최종 유효년월일을 제조년월일에서 사용(유효)기간을 계산하여 정확한 날짜가 나오는지 확인한다.

## B.20 신청수량 일부 감소 가능성

제조수량에서 특정 사유로 인해 일부가 누락되어 최종 신청 수량에는 더 적은 수량이 기입될 수 있음을 확인한다.

## B.21 제조년월일과 저장기간 시작일

제조년월일과 저장기간의 시작일은 같아야 하며, 허가된 저장기준을 기간으로 저장기간 시작일에서 계산하여 정확하게 작성되었는지 확인한다.

## B.22 제조량·사용량·분량·투입량 구분

제조량, 사용량, 분량, 투입량을 구분한다.

분량에 대한 항목을 검증할 때 정확한 정보를 추출해서 가져오는지 확인한다.

## B.23 SP 기준과 허가사항 기준 일치

허가사항 문서를 보유하고 있다면, SP 문서에 적힌 기준과 허가사항 문서에 적힌 기준의 단위와 수치가 일치하는지 확인한다.

## B.24 용기 규격별 기준 선택

50 mL 경우와 100 mL 경우처럼 시험 기준이 다른 경우, 각 항목에 맞는 시험 기준을 정확히 추출하여 확인한다.
