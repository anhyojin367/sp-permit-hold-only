# 회의 전 초안

이 문서는 회사 인터뷰 후 보완할 초안이다. 아래 항목은 확인 누락을 막는 체크리스트이며, 현재 SP나 허가서에 없는 값을 만들어 내는 판정 기준이 아니다.

# 중점 확인

- 백신 원액 및 완제 생산에서 세포주·시드·중간체·원액·완제의 추적성이 이어지는지 확인한다.
- 서로 다른 생산 플랫폼 또는 원료 분기가 있는 경우 제조번호와 제조일자가 다른 분기로 섞이지 않았는지 확인한다.
- 무균, 엔도톡신, 역가, 확인, 순도 등 중요 품질시험은 시험명과 적용 제조단계의 연결을 재확인한다.
- 냉장·냉동 보관조건과 시험일 또는 제조일의 관계를 확인할 때 현재 문서에 기재된 조건만 사용한다.
- 변경관리, 위탁시험, 제조소 구분이 표시된 경우 어떤 근거가 어느 제조단계에 적용되는지 추적한다.
- 스카이코비원멀티주 문서는 제품별 Markdown의 시험별 지정 단위표를 우선 적용하고, 지정 단위와 다른 시험기준 또는 시험결과 단위가 확인되면 단위불일치로 본다.

# 회의에서 확정할 내용

- 회사 내부 문서의 제조단계 표준 명칭과 약어
- 반드시 교차 확인해야 하는 중요 품질속성
- 회사 고유 제조번호 체계와 예외
- 위탁 제조·시험 및 제조소별 책임 범위
- 제품군별 필수 참고 문서와 우선순위
