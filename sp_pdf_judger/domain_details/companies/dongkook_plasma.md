# 회의 전 초안

- 원료혈장 여러 로트가 원획분 단계로 합류하는 구조를 보존하여 검토한다.
- 원료혈장별 제조번호와 제조년월일을 해당 원획분의 사용 원료 목록과 연결한다.
- 원획분의 제조량과 사용량을 구분하고, 제조요약도 제조량과는 제조량만 비교한다.
- 채장혈액원, 혈장 마스터파일, 바이러스 부정시험의 적용 범위를 확인한다.
- 최종원액과 완제의약품의 제조번호·제조일·제조수량을 다른 단계의 값으로 대체하지 않는다.

# 회의에서 확정할 내용

- 원료혈장 및 원획분의 묶음 규칙
- 채장혈액원 자료의 필수 확인 필드
- 제품별 용기 규격 선택 규칙
- 회사 고유 제조번호와 제조소 표기 규칙
