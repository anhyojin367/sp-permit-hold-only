# 회의 전 초안

GC녹십자 문서에 추가로 적용할 확인 목록이다. 구체적 기준값은 현재 SP, 허가서 또는 승인된 회사 기준에서만 가져온다.

# 중점 확인

- 혈장 유래 제품은 원료혈장, 혈장 풀 또는 획분, 원액, 완제의 추적성을 확인한다.
- 혈장 공급원, 혈장 마스터파일, 바이러스 안전성 관련 근거의 적용 범위를 확인한다.
- 제조번호, 제조일, 제조소가 서로 다른 단계에서 바뀌는 경우 정상적인 변환인지 확인한다.
- 수율, 사용량, 투입량을 제조량과 혼동하지 않는다.
- 완제 시험에서는 용기 규격, 농도, 포장단위에 해당하는 기준을 선택한다.

# 회의에서 확정할 내용

- 회사 문서의 원료혈장 및 획분 단계 표준 명칭
- 제조번호 체계와 단계 전환 규칙
- 혈장 공급원 및 바이러스 안전성 검토 범위
- 알부민 외 제품군에 공통으로 적용할 핵심 검수 항목
