# 제품 흐름

문서의 실제 단계명을 우선하되 일반적으로 원료혈장 → 혈장 풀 또는 원획분 → 최종원액 → 완제의약품 흐름을 확인한다.

# 중점 확인

- 원료혈장 로트가 어느 혈장 풀 또는 원획분에 사용되었는지 추적한다.
- 여러 원료혈장 또는 원획분이 합류할 때 제조번호와 제조일의 연결을 보존한다.
- 혈장 마스터파일, 채장혈액원, 바이러스 부정시험 및 바이러스 안전성 근거의 적용 범위를 확인한다.
- 제조량과 사용량·분량·투입량을 구분한다. 제조요약도 제조량은 본문의 제조량과만 비교한다.
- 제조요약정보에 제조량이 없으면 정보 없음으로 표시하되, 다른 제조량 정보가 명시된 단계의 비교까지 생략하지 않는다.
- 완제의 제조년월일은 분병일자나 시험일자가 아니라 제조년월일 필드와 비교한다.
- 용기 규격이 여러 개면 신청제품정보에서 선택된 규격에 해당하는 시험기준과 결과를 사용한다.
- 불용성미립자시험처럼 규격별 기준이 다른 시험은 현재 용기 규격과 입자 크기에 맞는 한 쌍만 비교한다.
- 구체적인 시험 수치나 허용범위는 현재 SP 또는 연결된 허가서에서만 사용한다.

# 회의에서 확정할 내용

- 원료혈장과 원획분 묶음 규칙
- 바이러스 안전성 자료의 필수 항목
- 제품 농도 및 용기 규격별 핵심 시험
- 회사별 공정 단계 명칭의 제품 공통명 매핑
