# 제품 흐름

- Component A: CHO 마스터 세포주 → CHO 제조용 세포주 → Component A 중간체원액
- Component B: E.coli 마스터 세포주 → E.coli 제조용 세포주 → Component B 중간체원액
- 합류 흐름: Component A 중간체원액, Component B 중간체원액 → 나노파티클원액 → 최종원액 → 완제의약품

# 중점 확인

- Component A와 Component B의 제조번호·제조일이 서로 뒤바뀌지 않았는지 확인한다.
- 각 분기 내부 선후관계와 두 분기가 합류한 뒤의 공통 선후관계를 모두 확인한다.
- 합류 공정의 날짜는 두 선행 중간체원액보다 빠를 수 없다.
- 세포주, 중간체원액, 나노파티클원액, 최종원액, 완제의 시험을 올바른 제조단계에 연결한다.
- 아래 시험항목은 제품별 지정 단위만 사용해야 하며, 문서 내 시험기준 또는 시험결과에 다른 단위가 기재되면 단위불일치로 본다.
- 구체적인 허용기준과 기준값은 현재 SP 또는 연결된 허가서에서만 사용한다.
