# 제공 더미 허가서의 실제 적용 범위 검토

## 결론

Component A 중간체 원액의 **시험 10개와 SP의 독립 배치 연결**은 확인했다.
그러나 제공 파일만으로 **전체 허가 공통조건 검토 완료 또는 무조건 필수시험 운영 활성화**를 선언하지 않는다.
이 문서는 더미 자료의 기술적 검토이며 실제 품목 허가·출하 승인이 아니다.
원본 PDF, 기존 27개 운영 MD, 기존 판정 결과와 UI는 변경하지 않았다.

- 파일: `더미데이터/260922[더미허가문서]스카이코비원멀티주.pdf`
- 원본 SHA256: `0c153c31ca738dfbf6a2b752ea09fa8a8ea9badbae3466d870c6a2279e77f8d2`
- 물리 23쪽 전체를 텍스트와 Poppler 렌더로 확인했다. 물리 쪽과 문서에 인쇄된 번호는 다르다.
- 전체 소유 문단 147개: 선택 시험 10개, 선택 시험 묶음 1개, 상위 문단 2개,
  독립 안내·변경 이력 22개, 나머지 범위 112개. 검색 상위 몇 건만 검토 목록에 넣지 않았다.
- 시험 하위트리 SHA256: `dbb226321db81bdc0db18f5bce5548864ab8f9326a957e8affc54a18581bfde7`
- 재현 가능한 전체 원문/위치/두 종류의 ID/검토 단서는
  `.local_validation/permit_review_v83/packet.json`과 `packet.md`에 있다.

## 전체성이 아직 확정되지 않은 이유

| 물리 쪽 | 원문에서 확인한 내용 | 다루는 방법 |
|---|---|---|
| 1 | 허가조건·제조방법·시험방법 등 여러 항목이 ‘별첨’ 참조 | 참조 문구만으로 첨부 내용을 읽은 것으로 간주하지 않음 |
| 2 | 변경 이력과 인쇄 번호 1/60 | 날짜만으로 해당 변경의 본문이나 최신 적용 범위를 추정하지 않음 |
| 3~17 | 인쇄 번호 5/60~19/60 | 보이는 시험/제조 내용의 원문 연결은 가능 |
| 18~21 | 인쇄 번호 52/60~55/60 | 번호가 뛰는 구간의 내용을 만들어내지 않음 |
| 22~23 | 인쇄 번호 59/60~60/60, 제품정보/제조원 | 다른 시험의 조건으로 합치지 않음 |

인쇄 번호 기준 2~4, 20~51, 56~58의 38개 번호는 제공 파일에서 관찰되지 않았다.
표지에는 이 번호가 없다. **이는 더미가 발췌된 형태라는 관찰이며 업로드 중 38쪽이 유실됐다는 판정이 아니다.**
스캔/업로드 오류로 단정하지 않았고 원본에 없던 페이지를 추가하지 않았다.
‘허가조건’ 변경 이력은 있지만 해당 별첨 조건의 완전한 적용 내용을 제공 파일에서 확정할 수 없다.
현재 자료에서 찾은 조건이 전부라는 주장과, 현재 자료를 빠짐없이 추출했다는 주장을 구별해야 한다.

## Component A 중간체 10시험의 국소 원문 검토

정확한 경로: `제조방법 및 시험기준 / Component A 중간체 원액 / Component A 중간체 원액에 대한 시험`.
상위 `2.`는 제조방법 및 시험기준 장, `2.2.`는 본배양·정제 공정 및 -70℃ 이하 보관 설명이다.
읽을 수 있는 상위 원문과 아래 10시험 본문에서는 용기 규격·차수에 따른 **시험 자체의 면제**를 발견하지 못했다.
이 관찰은 외부/미제공 공통조건이 없다는 보증이나 무조건 필수의 자동 승인이 아니다.

| 2.2.2.1 | 성상 | 투명 또는 약간 탁한 무색/황색 액상 | 11 |

자동 원문 소유 구간에는 다음 페이지 머리말이 포함될 수 있다. 예를 들어 pH 문단의 소유 페이지 목록은
11~12지만 pH 기준의 실제 내용은 11쪽이다. 표의 내용 쪽과 전체 소유 구간 목록을 혼동하지 않는다.
유럽약전·대한민국약전 및 자사 시험법을 참조한 문장은 참조 대상의 모든 본문을 검토한 것으로 간주하지 않는다.
위 요지는 LLM에 주는 정답이나 새 판정 규칙이 아니라 이 파일의 해당 범위를 사람이 읽기 위한 설명이다.

## 다른 단계 조건을 가져오지 않는 예

- 물리 16쪽 나노파티클 SE-HPLC와 20쪽 항원바이알 SE-HPLC의 135~562 μg/mL 구간은
  ‘희석 없이 분석’하는 **절차 조건**이다. 시험 전체의 생략 근거가 아니다.
- 이 조건을 Component A 중간체의 시험으로 복사하지 않는다. 동일한 시험명/반복된 절 번호도
  문서 지문과 전체 경로·소유 ID가 다르면 별개다.
- SP의 `SKY-CA220705`는 중간체 정보 절의 독립 제조번호다. 같은 페이지의 Component B 번호나
  머리말 완제품 제조번호를 빌리지 않는 기존 진단 시험을 다시 통과했다.
- 본배양액의 별도 배치 연결 부족은 중간체 연결 성공으로 해결된 것이 아니다.

## 추가한 도구와 재현 방법

`scripts/build_permit_review_packet.py`는 기존 전체 원문 소유 목록과 필수시험 목록을 재사용한다.
두 목록의 말단 시험을 전체 경로/절 번호/원본 파일로 일대일 대조하고, 모든 상위·독립·다른 문단도 보존한다.
문서 추출 실패·누락·중복·변조·다른 원본·실행 중 변경은 거부한다. 자료에는 원문 페이지/정규화 문자 위치/
인용/문단 ID/구간 ID를 남긴다. 기존 검토 파일은 덮어쓰지 않는다.

```powershell
.\.venv\Scripts\python.exe scripts/build_permit_review_packet.py `
  --permit '더미데이터/260922[더미허가문서]스카이코비원멀티주.pdf' `
  --stage-title '제조방법 및 시험기준' `
  --stage-title 'Component A 중간체 원액' `
  --stage-title 'Component A 중간체 원액에 대한 시험' `
  --output-dir .local_validation/permit_review_new
.\.venv\Scripts\python.exe -m pytest -q tests/test_permit_review_packet.py
```

번호 검사는 단독 줄의 `n/총쪽수` **후보**를 찾는 제한된 진단이다. 분수/다른 페이지 체계를 혼동할 수 있어
문서 완전성을 자동 판정하지 않는다. ‘별첨/경우/생략/희석 없이’ 등의 단어도 검토 단서일 뿐이고,
단어가 없다는 이유로 무조건 필수로 분류하지 않는다. 원문 전체를 남기는 이유다.
모든 자료는 `unreviewed`, `runtime_activation: false`로 생성된다. 체크박스/지문은 승인 서명이 아니다.
CLOVA 호출·SP 재판정·운영 규칙 변경·UI 변경은 하지 않는 별도 진단 도구다.

## 남은 작업

현재 제공 범위에 근거한 설명/후보와 최종 의무 승인을 분리한 상태로, 자연어 조건을 원문 ID에 연결하는
독립 CLOVA 초안 도구를 추가했다. `PERMIT_OBLIGATION_DRAFT.md` 참조. v86의 전체 원문 응답은 완비했지만
복합 의미 표본에서 분류 누락을 발견하여 운영에는 연결하지 않았다. 의미 계약의 보완/검토가 남았다.
초안은 전체 원문 검토 누락/근거 부족/외부 참조를 명시해야 하고, 임의 면제나 자동 운영 활성화로 이어지면
안 된다. 이후 확정된 범위의 MD와 오류 PDF를 검증해야 한다.
현재 자료만으로 확인되지 않는 전체 공통조건, 복수 개정 관계, 본배양 배치 연결은 계속 미확정이다.
