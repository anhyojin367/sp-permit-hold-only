# 2026-09-29 사용자 제보 수정

이 문서는 개발 폴더의 변경 기록이다. 9월 28일 전달 ZIP은 고정 사본으로 변경하지 않았다.

## 1. D02: 결과값 합격과 시험 전체 합격은 다르다

성숙마우스 생존율 85%는 80% 이상 조건에 맞지만, 2024.10.29~11.10은 12일로 MD R10의 최소 28일을 만족하지 않는다.
이전에는 R10 카드만 불충족이었고, 해당 시험 카드는 생존율 비교만 표시했다.

- `policy_engine.duration`이 정확한 시험 `order_idx`와 기간 판정을 반환한다.
- `policy_summary.apply_policy_test_guards`가 해당 시험의 최종 상태에도 불충족을 반영한다.
- 다른 단계의 동명 시험에는 적용하지 않는다. 종전 수치 판정은 이유와 감사 기록에 남긴다.
- 단위·자릿수·수치·허가 시험방법 비교도 명백히 위반한 개별 레코드에만 불충족을 전달한다. 문서 전체의 실패를 모든 시험에 복사하지 않는다.
- 정상 기간은 기존 결과값 판정을 승격하지 않는다. 기간 근거 누락은 보류이고, 이미 증명된 불충족을 보류로 낮추지 않는다.

## 2. 엔도톡신 보류의 실제 원인

SP에는 기준 `820 EU/mL 미만`, 결과 `760 EU/mL`로 적혀 있어 SP 숫자 비교만으로는 충족이다.
그러나 제공 허가서 물리 14쪽의 2.3.1.8에는 `820 EU/mg of protein 미만`으로 적혀 있다.
부피당 수치와 단백질 질량당 수치를 환산 근거 없이 같다고 할 수 없다.

허가 기준 우선이라는 기존 요구를 유지한다. 화면의 이유 상자에서는 허가서에서 가져온 기준을 **적용 허가서 기준**이라고 명시한다.
이는 OCR 오인으로 확인된 문제가 아니므로 원본이나 결과값을 임의로 바꾸지 않았다.

## 3. 무균시험의 실제 관측과 요구 문장

`균이 확인되지 않아야 함`은 기준이고, `균이 확인되지 않음`은 음성 관측이다. 후자는 충족이다.
하지만 D00/D02 물리 19쪽(인쇄18/25)의 결과란은 실제로 전자의 요구 문장을 그대로 반복한다.
이 문장을 음성 관측으로 꾸며 합격 처리하지 않고 실제 결과 확인이 필요한 보류로 유지한다.

추가된 D15/D16은 Component A 중간체원액(3.2.2) 무균시험의 결과를 각각 `x`, `불검출`로 바꾼 자료다.
제공 B.15 요구사항에 따라 `x/X`를 불검출 표기로 해석하는 사전을 MD에 추가했다.
제품·시험명·시험기준·결과가 사전의 범위와 정확히 맞을 때만 적용하며 원문은 계속 표시한다.
`불검출`, `균이 확인되지 않음`은 기존 정성 비교에서 충족되는 것을 별도 시험으로 확인한다.

## 4. 새 더미와 MD

| 문서 | 기대 | 구현 |
|---|---|---|
| D13 | 최종원액 공정/시험 전체 누락 검출 | R29, 해당 단계의 성상·무균시험 존재 검사 |
| D14 | 나노파티클 270 L + 완충액 15 L와 제조량 270 L 불일치 | R30, 직접 투입량 합계 일치 검사. 기존 R05 제조요약도 대조도 적용 |
| D15 | 무균시험 `x`를 해당 범위에서 음성으로 해석 | `result_aliases` |
| D16 | 무균시험 `불검출` 충족 | 기존 정성 비교 회귀 검증 |

오류를 만들어 둔 PDF만 있는 것은 아니다. D15/D16의 음성 표기는 정상 표기 변형이므로 억지로 불충족을 만들면 오탐이다.
판정에는 D번호나 파일명을 사용하지 않는다. 파일명은 검증 스크립트에서 정답 사례를 찾을 때만 사용한다.

`sp_pdf_judger/rules/sky_covione.md`의 예:

```yaml
result_aliases:
  - products: [스카이코비원멀티주]
    test: 무균시험
    criteria: 균이 확인되지 않아야 함
    values: [x]
    normalized_result: 균이 확인되지 않음
    reason: 이 제품·시험의 X는 불검출 표기
```

여기서 소문자/대문자·공백은 정규화한다. 다른 제품·시험, 양성이어야 하는 기준, `x / 양성` 같은 복합 결과에는 적용하지 않는다.
겹치는 사전 정의는 시작 시 오류로 거부한다. 이 사전은 판정을 강제하는 것이 아니라 결과의 표현만 정규화하고 다시 정상 판정 경로에 넣는다.

`mass_balance`는 기존 `not_exceed`(합계 초과 금지)를 기본으로 유지한다. R30만 `comparison: equal`(합계 일치)을 명시한다.
손실이 가능한 다른 제조공정까지 일치 조건을 강제하지 않는다. 누락 수량·다른 단위는 보류한다.

## 5. 문서함과 기존 결과 캐시

접수일과 허가서 사이에 **문서 제목** 행을 추가했다. 업로드 원래 파일명을 보여주므로 D00/D02를 구분할 수 있다.
상단의 공통 SP 제목과 기존 레이아웃은 유지한다. 파일명은 HTML 이스케이프하여 표시한다.

이전 검수 결과를 수정된 판정으로 오인하지 않도록 판정/화면 캐시 버전을 v104로 올렸다(중간 v103에서 만든 결과도 새로 검수한다).
기존 산출물은 삭제하지 않는다. 수정 적용 뒤 목록에서 검수 전으로 보이는 문서는 **검수 진행**으로 새 판정을 실행해야 한다.

## 6. 추가 발견 오류

D15의 생소한 결과 표기가 일반시험법 검사로 들어갈 때 `GENERIC_EXTERNAL_CRITERIA_RE`의 누락 참조로 중단되는 오류를 재현했다.
원래 참조하던 정규식 상수를 복구하고, 직접 부재 기준과 허가서 참조 기준 두 경우의 재현 시험을 추가했다.

전체 PDF 검증에서는 별도 일반시험법 경로가 `불검출` 안의 `검출`을 양성으로 읽는 오탐도 확인했다.
음성 표현만 제외하고 나머지 관측을 검사하도록 수정했다. `A 불검출, B 검출`처럼 실제 양성이 함께 있으면 계속 불충족이다.
개별 판정기 시험만 통과해도 후속 일반시험법에서 결과를 잘못 바꿀 수 있어 이 경로의 회귀시험도 추가했다.
